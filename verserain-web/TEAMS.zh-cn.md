# 云端家人(原:陪伴团队 / 我的团队)使用说明

> 「两个人总比一个人好,因为二人劳碌同得美好的果效。」— 传道书 4:9

「陪伴团队」是 VerseRain 里的小团体读经功能 —
**用来陪伴,不是用来比赛**。
管理员开团、订进度,团员一起读经、写心得、彼此打气。

## 核心设计原则

整个团队功能由四个原则贯穿,不会轻易动摇:

1. **不排名**。所有列表按「加入顺序」或「最近活动」,**永远不按完成数或点数排序**。
2. **不显示落后**。团员进度不秀「第几名」、不秀「比某人少几节」。
3. **里程碑式回馈,不是分数比较**。完成一节 → 显示「✓ 完成」,不秀分数差距。
4. **管理员是牧者,不是裁判**。可以设进度、可以发起,但不能 punish 退步者。

点数系统的存在**不是为了比较**,而是让你看见:
- 自己这周的成长(个人里程碑)
- 全团一起的果子(共同庆祝)

## 快速上手

### 加入一个团队

方法一 **扫 QR Code**
1. 管理员打开团队「管理」页 → 点 **QR** 按钮
2. 用手机相机扫一下
3. 自动进入加入画面,确认 → 完成

方法二 **点分享链接**
1. 管理员传给你 `https://www.verserain.com/?join=XXX-XXXX` 之类的链接
2. 点链接 → App 自动展开加入画面,邀请码预先填好
3. 点「加入」→ 完成

方法三 **手动输入邀请码**
1. 在 App 点上方导览列的 **「陪伴团队」**
2. 点「用邀请码加入」
3. 输入像 `IZ2-5HAF` 的 7 字短码(大小写没差)
4. 确认 → 完成

> **同时可加入多个团队**:你可以同时参与 20 个团,在每个团扮演不同角色 —
> 某团是管理员,另一团单纯当团员。

### 建立一个团队

1. 点 **「陪伴团队」** → 点「+ 建立团队」
2. 给团队取一个名字(80 字内)+ 简短描述(500 字内,选填)
3. 系统自动分配一个邀请码
4. 你就是这团的**建立者+第一个管理员**

> 每人最多可以**自己建立 5 个团**(避免 spam)。
> 一个团最多 **8 位管理员、200 位团员**。

## 功能逐一说明

### 读经进度表

管理员在「管理」页设计一系列「项目」,每个项目代表一段经文(经文组)。每个项目包含:

- **标题**(必填) — 例:「诗篇 37 — 承受地土」
- **setId**(必填) — 对应 VerseRain 既有经文组 id,或自填一个
- **经文清单** — 逗号分隔的引用,如 `诗 37:3, 诗 37:4, ...`
- **目标日期**(选填) — 软性目标,逾期**不会**被责备
- **给团员的话**(选填,800 字内) — 为什么选这段、怎么默想

团员在团队详情页看到每个项目:
- 完成度 `X / N`
- 描述展开
- 经文按钮 — 点一下标记完成(绿色 ✓),再点取消

### 心得 / 代祷分享

每个进度项目下方有「**心得 · 代祷**」串。

点 **+ 心得** 或 **+ 代祷** 弹出写作视窗:
- 可选「整段」或「某一节」(verseRef)
- 写 1000 字内
- 送出后**所有团员都看得到**

**「心得」与「代祷」差异**:
- 心得(蓝色标) — 个人领受、反思、见证
- 代祷(紫色标) — 请小组为你的事情代祷

两种都可以由其他团员按 emoji 回应(❤️ 🙏 ✨ 🌧️)。
**作者可删自己的、管理员也可删(轻度节制)**。
**目前不能编辑** — 为了保留 journal 的真实,不允许 retroactive 改写;
这是刻意设计。

### 鼓励(Cheer)

对团员的「鼓励」有两种形式 — 都显示在团队上方的「最近的鼓励」区。

1. **一键 emoji** — 在团员卡片上点 ❤️ / 🙏 / ✨ / 🌧️
2. **留言** — 点「留言」展开,写 140 字 + 选 emoji,送出

对「心得 / 代祷」的回应是另一条路径:
- 在心得卡片底部点 emoji
- 同一篇对同一人**只能每种 emoji 1 票**(类 LINE 表情)
- 再点一次取消(取消不退点数)

### 本团果园(统计面板)

每个团员进团都会看到一个渐层绿卡:

```
🌳 本团果园
  你这周       你共有        本团这周
   30 🍎         30 🍎         58 🍎
                                 3/7 位团员有活动
```

- **你这周** — 你这一周(周一 UTC 重置)在这个团赚到的果实
- **你共有** — 你所有团队累积的总果实(整合 garden,不分团)
- **本团这周** — 全团这周共同的成果 +「N/M 位团员有活动」
- **绝对不**显示其他团员的个人点数
- **绝对不**排名

### 关心提示(管理员)

只有管理员看见的橘色卡。自动侦测两种状况:

- **N 位团员还没打开过进度表** — 点开展开个别名单 + 4 颗 emoji 快速送鼓励
- **N 位团员 7 天没有新进度** — 同上

设计用意:**不打扰、不通知团员「你被点名」**,而是给管理员一个牧养工具,
让他可以**主动关心**沉默的人。

## 点数奖励机制

点数**整合进 VerseRain 既有的「果实 garden」** —
你在团队里赚的点直接累进你的个人果园。没有独立货币。

### 完整点数表

| 动作 | 点数 | 上限 / 规则 |
|---|:---:|---|
| **🌱 个人读经** |  |  |
| 标记一节完成(首次) | **3** | 每节经文一生只算一次(跨团不重复) |
| **🌳 写心得 / 代祷(深度分享)** |  |  |
| 写一篇心得 | **15** | 同一项目同一天只算第一篇 |
| 写一篇代祷 | **15** | 同上 |
| 你的心得被别人按 emoji 回应 | **+2** | 每位回应者只算一次(防刷) |
| **💗 陪伴他人** |  |  |
| 对团员卡片送 emoji(快速 cheer) | **1** | 每天上限 10 次 = 10 点 |
| 对团员卡片写留言(text cheer) | **5** | 每天上限 5 则 = 25 点 |
| 对心得 / 代祷按 emoji 回应 | **2** | 每天上限 20 次 = 40 点 |
| **👑 管理员建造** |  |  |
| 建立一个新团队 | **20** | 一次性 |
| 进度表项目有经文清单 | **10** | 每项目一次性 |
| 进度表项目有有意义的描述(> 20 字) | **5** | 每项目一次性 |

### 典型每日点数情境

| 场景 | 算法 | 一日总和 |
|---|---|---|
| 安静的观察者:只读 1 节 | 1×3 | **3 🍎** |
| 认真读经的普通团员:3 节 + 1 心得 + 3 emoji + 2 reactions | 9 + 15 + 3 + 4 | **31 🍎** |
| 热心陪伴者:1 节 + 1 心得 + 1 代祷 + 5 emoji + 2 留言 + 5 reactions | 3+15+15+5+10+10 | **58 🍎** |
| 牧者建团当天(一次性):建团 + 5 schedule items + 3 有描述 + 1 心得 | 20+50+15+15 | **100 🍎**(之后回到普通) |

### 设计用意

- 「**写心得 (15)**」≈「**读 5 节经文 (15)**」 — 质与量同等重要
- 「**留言鼓励 (5)**」> 「**快速 emoji (1)**」 — **用心**比 reaction spam 值钱
- 「**reactions 一天上限 20 次 = 40 点**」≈「**读完整章经文**」— 陪伴和读经都重要
- **管理员一次性大笔**(100 点建团当天) — 奖励牧养者的辛苦起头,
  但**之后不重复** — 不让「管理员身分」变成永久 buff

## 反滥用守则

| 机制 | 阻挡什么 |
|---|---|
| **eventKey 幂等写入** | 同节经文反覆「标记/取消」不会重复拿点 |
| **每日上限 (per bucket)** | 对 100 人按 emoji 也只能拿 10 点 |
| **每项目每日只计一篇心得** | 写 50 条一字心得也只有 15 点 |
| **取消按赞不退点数** | 防止「按了拿点,取消再按」的循环刷 |
| **作者收回应点数 unique per 回应者** | 找朋友狂按同一篇也只给作者 +2 一次 |
| **建团点数一次性** | 不能解散重建拿 20 点 |
| **Server-side 强制** | 不信任 client 报的点数,后端用 `points-journal` 锁死 |

## 常见问题

**Q1:点数会不会在团队里排名?**
不会。**永远不会**。团员间互看的只有「已完成 N 节」,不显示彼此点数。
你只看得到自己这周/总计,以及全团集体本周总数。

**Q2:我同时加入 3 个团,读同一节经文会拿 3 次点数吗?**
不会。「读一节」是个人的事 — 一节经文一生只计一次 3 点,跨团不重复。
但你的「分享心得」「鼓励」是社群动作,在不同团都会独立计算
(不同团的人需要不同的见证 — 写两篇不是刷)。

**Q3:管理员建团+建 schedule 一次拿 100 点,公平吗?**
建团当天可能爆 100+,但**那是 one-shot**。第二天起跟普通团员一样。
牧者打地基的辛苦值得一次性肯定,长期不会永远 +50% buff。

**Q4:点数会清零吗?**
- **个人累计总果实**(你共有)— 永不归零
- **个人这周**(你这周)— 每周一 UTC 00:00 重置
- **本团这周**(全团)— 同上

**Q5:我如果离开团队,过去拿的点数会被收回吗?**
不会。点数累计在你的个人果园(garden),离团不影响。
但你后续就无法看到那个团的活动了。

**Q6:管理员可以帮团员加点数吗?**
不能。点数由系统根据实际动作自动发放,管理员无权手动调整。
这是刻意保持公平的设计。

**Q7:可以匿名分享心得吗?**
目前不行。「陪伴」前提之一是知道是谁在说话。
未来若多人小组有此需求,会再评估。

**Q8:被别人写的内容让我不舒服怎么办?**
- 找管理员 — 管理员可以删除任何团员的心得/代祷
- 留言鼓励滥用 → 管理员目前可看见发送者,可以私下沟通
- 真的有恶意团员 → 管理员可以解散整团再重建(旧邀请码立即失效)

**Q9:我可以建立完全不订进度表的「纯陪伴」团吗?**
可以。`schedule.items = []` 是合法状态。
团员之间还是可以鼓励、写日常见证(虽然得不到「进度」相关点数)。

**Q10:可不可以关掉点数系统?**
目前不行 — 点数是预设行为。
不过因为**不排名、不弹窗**,如果你完全不在乎,把它当背景音也可以。
