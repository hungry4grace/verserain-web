# 陪伴團隊(我的團隊)使用說明

> 「兩個人總比一個人好,因為二人勞碌同得美好的果效。」— 傳道書 4:9

「陪伴團隊」是 VerseRain 裡的小團體讀經功能 —
**用來陪伴,不是用來比賽**。
管理員開團、訂進度,團員一起讀經、寫心得、彼此打氣。

## 核心設計原則

整個團隊功能由四個原則貫穿,不會輕易動搖:

1. **不排名**。所有列表按「加入順序」或「最近活動」,**永遠不按完成數或點數排序**。
2. **不顯示落後**。團員進度不秀「第幾名」、不秀「比某人少幾節」。
3. **里程碑式回饋,不是分數比較**。完成一節 → 顯示「✓ 完成」,不秀分數差距。
4. **管理員是牧者,不是裁判**。可以設進度、可以發起,但不能 punish 退步者。

點數系統的存在**不是為了比較**,而是讓你看見:
- 自己這週的成長(個人里程碑)
- 全團一起的果子(共同慶祝)

## 快速上手

### 加入一個團隊

方法一 **掃 QR Code**
1. 管理員打開團隊「管理」頁 → 點 **QR** 按鈕
2. 用手機相機掃一下
3. 自動進入加入畫面,確認 → 完成

方法二 **點分享連結**
1. 管理員傳給你 `https://www.verserain.com/?join=XXX-XXXX` 之類的連結
2. 點連結 → App 自動展開加入畫面,邀請碼預先填好
3. 點「加入」→ 完成

方法三 **手動輸入邀請碼**
1. 在 App 點上方導覽列的 **「陪伴團隊」**
2. 點「用邀請碼加入」
3. 輸入像 `IZ2-5HAF` 的 7 字短碼(大小寫沒差)
4. 確認 → 完成

> **同時可加入多個團隊**:你可以同時參與 20 個團,在每個團扮演不同角色 —
> 某團是管理員,另一團單純當團員。

### 建立一個團隊

1. 點 **「陪伴團隊」** → 點「+ 建立團隊」
2. 給團隊取一個名字(80 字內)+ 簡短描述(500 字內,選填)
3. 系統自動分配一個邀請碼
4. 你就是這團的**建立者+第一個管理員**

> 每人最多可以**自己建立 5 個團**(避免 spam)。
> 一個團最多 **8 位管理員、200 位團員**。

## 功能逐一說明

### 讀經進度表

管理員在「管理」頁設計一系列「項目」,每個項目代表一段經文(經文組)。每個項目包含:

- **標題**(必填) — 例:「詩篇 37 — 承受地土」
- **setId**(必填) — 對應 VerseRain 既有經文組 id,或自填一個
- **經文清單** — 逗號分隔的引用,如 `詩 37:3, 詩 37:4, ...`
- **目標日期**(選填) — 軟性目標,逾期**不會**被責備
- **給團員的話**(選填,800 字內) — 為什麼選這段、怎麼默想

團員在團隊詳情頁看到每個項目:
- 完成度 `X / N`
- 描述展開
- 經文按鈕 — 點一下標記完成(綠色 ✓),再點取消

### 心得 / 代禱分享

每個進度項目下方有「**心得 · 代禱**」串。

點 **+ 心得** 或 **+ 代禱** 彈出寫作視窗:
- 可選「整段」或「某一節」(verseRef)
- 寫 1000 字內
- 送出後**所有團員都看得到**

**「心得」與「代禱」差異**:
- 心得(藍色標) — 個人領受、反思、見證
- 代禱(紫色標) — 請小組為你的事情代禱

兩種都可以由其他團員按 emoji 回應(❤️ 🙏 ✨ 🌧️)。
**作者可刪自己的、管理員也可刪(輕度節制)**。
**目前不能編輯** — 為了保留 journal 的真實,不允許 retroactive 改寫;
這是刻意設計。

### 鼓勵(Cheer)

對團員的「鼓勵」有兩種形式 — 都顯示在團隊上方的「最近的鼓勵」區。

1. **一鍵 emoji** — 在團員卡片上點 ❤️ / 🙏 / ✨ / 🌧️
2. **留言** — 點「留言」展開,寫 140 字 + 選 emoji,送出

對「心得 / 代禱」的回應是另一條路徑:
- 在心得卡片底部點 emoji
- 同一篇對同一人**只能每種 emoji 1 票**(類 LINE 表情)
- 再點一次取消(取消不退點數)

### 本團果園(統計面板)

每個團員進團都會看到一個漸層綠卡:

```
🌳 本團果園
  你這週       你共有        本團這週
   30 🍎         30 🍎         58 🍎
                                 3/7 位團員有活動
```

- **你這週** — 你這一週(週一 UTC 重置)在這個團賺到的果實
- **你共有** — 你所有團隊累積的總果實(整合 garden,不分團)
- **本團這週** — 全團這週共同的成果 +「N/M 位團員有活動」
- **絕對不**顯示其他團員的個人點數
- **絕對不**排名

### 關心提示(管理員)

只有管理員看見的橘色卡。自動偵測兩種狀況:

- **N 位團員還沒打開過進度表** — 點開展開個別名單 + 4 顆 emoji 快速送鼓勵
- **N 位團員 7 天沒有新進度** — 同上

設計用意:**不打擾、不通知團員「你被點名」**,而是給管理員一個牧養工具,
讓他可以**主動關心**沉默的人。

## 點數獎勵機制

點數**整合進 VerseRain 既有的「果實 garden」** —
你在團隊裡賺的點直接累進你的個人果園。沒有獨立貨幣。

### 完整點數表

| 動作 | 點數 | 上限 / 規則 |
|---|:---:|---|
| **🌱 個人讀經** |  |  |
| 標記一節完成(首次) | **3** | 每節經文一生只算一次(跨團不重複) |
| **🌳 寫心得 / 代禱(深度分享)** |  |  |
| 寫一篇心得 | **15** | 同一項目同一天只算第一篇 |
| 寫一篇代禱 | **15** | 同上 |
| 你的心得被別人按 emoji 回應 | **+2** | 每位回應者只算一次(防刷) |
| **💗 陪伴他人** |  |  |
| 對團員卡片送 emoji(快速 cheer) | **1** | 每天上限 10 次 = 10 點 |
| 對團員卡片寫留言(text cheer) | **5** | 每天上限 5 則 = 25 點 |
| 對心得 / 代禱按 emoji 回應 | **2** | 每天上限 20 次 = 40 點 |
| **👑 管理員建造** |  |  |
| 建立一個新團隊 | **20** | 一次性 |
| 進度表項目有經文清單 | **10** | 每項目一次性 |
| 進度表項目有有意義的描述(> 20 字) | **5** | 每項目一次性 |

### 典型每日點數情境

| 場景 | 算法 | 一日總和 |
|---|---|---|
| 安靜的觀察者:只讀 1 節 | 1×3 | **3 🍎** |
| 認真讀經的普通團員:3 節 + 1 心得 + 3 emoji + 2 reactions | 9 + 15 + 3 + 4 | **31 🍎** |
| 熱心陪伴者:1 節 + 1 心得 + 1 代禱 + 5 emoji + 2 留言 + 5 reactions | 3+15+15+5+10+10 | **58 🍎** |
| 牧者建團當天(一次性):建團 + 5 schedule items + 3 有描述 + 1 心得 | 20+50+15+15 | **100 🍎**(之後回到普通) |

### 設計用意

- 「**寫心得 (15)**」≈「**讀 5 節經文 (15)**」 — 質與量同等重要
- 「**留言鼓勵 (5)**」> 「**快速 emoji (1)**」 — **用心**比 reaction spam 值錢
- 「**reactions 一天上限 20 次 = 40 點**」≈「**讀完整章經文**」— 陪伴和讀經都重要
- **管理員一次性大筆**(100 點建團當天) — 獎勵牧養者的辛苦起頭,
  但**之後不重複** — 不讓「管理員身分」變成永久 buff

## 反濫用守則

| 機制 | 阻擋什麼 |
|---|---|
| **eventKey 冪等寫入** | 同節經文反覆「標記/取消」不會重複拿點 |
| **每日上限 (per bucket)** | 對 100 人按 emoji 也只能拿 10 點 |
| **每項目每日只計一篇心得** | 寫 50 條一字心得也只有 15 點 |
| **取消按讚不退點數** | 防止「按了拿點,取消再按」的循環刷 |
| **作者收回應點數 unique per 回應者** | 找朋友狂按同一篇也只給作者 +2 一次 |
| **建團點數一次性** | 不能解散重建拿 20 點 |
| **Server-side 強制** | 不信任 client 報的點數,後端用 `points-journal` 鎖死 |

## 常見問題

**Q1:點數會不會在團隊裡排名?**
不會。**永遠不會**。團員間互看的只有「已完成 N 節」,不顯示彼此點數。
你只看得到自己這週/總計,以及全團集體本週總數。

**Q2:我同時加入 3 個團,讀同一節經文會拿 3 次點數嗎?**
不會。「讀一節」是個人的事 — 一節經文一生只計一次 3 點,跨團不重複。
但你的「分享心得」「鼓勵」是社群動作,在不同團都會獨立計算
(不同團的人需要不同的見證 — 寫兩篇不是刷)。

**Q3:管理員建團+建 schedule 一次拿 100 點,公平嗎?**
建團當天可能爆 100+,但**那是 one-shot**。第二天起跟普通團員一樣。
牧者打地基的辛苦值得一次性肯定,長期不會永遠 +50% buff。

**Q4:點數會清零嗎?**
- **個人累計總果實**(你共有)— 永不歸零
- **個人這週**(你這週)— 每週一 UTC 00:00 重置
- **本團這週**(全團)— 同上

**Q5:我如果離開團隊,過去拿的點數會被收回嗎?**
不會。點數累計在你的個人果園(garden),離團不影響。
但你後續就無法看到那個團的活動了。

**Q6:管理員可以幫團員加點數嗎?**
不能。點數由系統根據實際動作自動發放,管理員無權手動調整。
這是刻意保持公平的設計。

**Q7:可以匿名分享心得嗎?**
目前不行。「陪伴」前提之一是知道是誰在說話。
未來若多人小組有此需求,會再評估。

**Q8:被別人寫的內容讓我不舒服怎麼辦?**
- 找管理員 — 管理員可以刪除任何團員的心得/代禱
- 留言鼓勵濫用 → 管理員目前可看見發送者,可以私下溝通
- 真的有惡意團員 → 管理員可以解散整團再重建(舊邀請碼立即失效)

**Q9:我可以建立完全不訂進度表的「純陪伴」團嗎?**
可以。`schedule.items = []` 是合法狀態。
團員之間還是可以鼓勵、寫日常見證(雖然得不到「進度」相關點數)。

**Q10:可不可以關掉點數系統?**
目前不行 — 點數是預設行為。
不過因為**不排名、不彈窗**,如果你完全不在乎,把它當背景音也可以。
